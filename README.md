<h1>🛒 QuickKart — Modern Full-Stack E-Commerce Platform</h1>
<p>
QuickKart is a fully-featured, production-ready e-commerce application built using the <b>MERN (MongoDB, Express, React, Node.js)</b> stack.  
It includes product browsing, shopping cart, PayPal-based checkout, and a complete admin dashboard.
</p>
<h1>🔗 Project Links</h1>
Live Demo: https://quick-kart-yybb.vercel.app
<h2>🚀 Features</h2>
<h3>🧑‍💻 User Features</h3>
<ul>
  <li>Browse products by category</li>
  <li>Product details page</li>
  <li>Add to Cart / Remove from Cart</li>
  <li>Update item quantity</li>
  <li>Secure Checkout with PayPal Payment Gateway</li>
  <li>User authentication (Register/Login)</li>
  <li>Persistent cart across sessions</li>
  <li>Order history</li>
  <li>Profile update</li>
</ul>
<h3>🛠 Admin Features</h3>
<ul>
  <li>Admin authentication & protected routes</li>
  <li>Add / Edit / Delete products</li>
  <li>Manage users</li>
  <li>View all orders</li>
  <li>Update order status</li>
  <li>Dashboard overview</li>
</ul>
<h1>🏗 Tech Stack</h1>
<h3>🎨 Frontend</h3>
<ul>
  <li>React.js</li>
  <li>Redux Toolkit</li>
  <li>React Router</li>
  <li>Tailwind CSS</li>
  <li>Axios</li>
  <li>React Icons</li>
</ul>
<h3>⚙️ Backend</h3>
<ul>
  <li>Node.js</li>
  <li>Express.js</li>
  <li>MongoDB + Mongoose</li>
  <li>PayPal Payment Gateway</li>
  <li>JWT Authentication</li>
  <li>Bcrypt for password hashing</li>
</ul>
<h1>💳 Payment Integration</h1>
<ul>
  <li>Secure payment via PayPal</li>
  <li>Fast and trusted user experience</li>
  <li>Auto-captures and sends payment confirmation to backend</li>
  <li>Order stored securely in MongoDB</li>
</ul>
